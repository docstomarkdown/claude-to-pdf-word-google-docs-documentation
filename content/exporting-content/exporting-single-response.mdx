# Exporting a Single Response

The **Claude to Word or PDF** extension allows you to export any individual response from Claude into a cleanly formatted Word or PDF document.

## How to Export

To export a single response:

1. Open any conversation on [Claude](https://claude.ai).
2. Look for the **Word** and **PDF** buttons at the bottom right corner of each response.
3. Click either button to download the response in your chosen format.

## Example

![Screenshot showing export buttons at the bottom right corner of a Claude response](/chatgpt-single-response-export.png)


The exported file will preserve:

- Headings and paragraph structure
- Bullet points and numbered lists
- Code blocks and markdown formatting
- Math equations (rendered properly in Word)
- Tables and indentation

No extra formatting required — the document is ready to use or share.


> **Tip:** Use this feature to quickly save summaries, code snippets, or explanations without copying and pasting manually.
