# Changelog

All notable updates to the **Claude to Word or PDF** Chrome extension are listed below.

---

## v1.5.0 – April 2025

- Introduced **license management system** with support for free and paid plans.
- Usage limits implemented to enforce monthly limits based on license tier.
- UI updates in the popup for license activation and plan info.

## v1.4.0 – April 2025

- Added support for exporting **artifact content** when an artifact is open in full view (Claude UI).
- Enhanced equation handling for better compatibility with Microsoft Word.
- Improved layout for conversation exports, especially on long chats.

## v1.3.0 – March 2025

- Introduced the ability to export **entire conversations** in one click.
- Improved file formatting and heading structure in Word exports.
- Fixed issues with long code blocks getting cut off in PDFs.

## v1.2.0 – March 2025

- Polished export button placement and styling.
- Enhanced PDF generation engine for better accuracy.

## v1.1.0 – February 2025

- Bug fixes related to special characters and unicode formatting.
- Minor performance improvements.

## v1.0.0 – February 2025

- Initial release of the extension.
- Export individual Claude responses as cleanly formatted Word or PDF documents.
- Support for text, code, lists, and basic markdown formatting.
- One-click download button under each response.
